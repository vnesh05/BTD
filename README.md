# Brain Tumour Detection Using CNN

## 📌 Project Overview
Brain tumours are abnormal cell growths in the brain that can be life-threatening if not detected early. Traditional diagnosis relies on radiologists manually examining MRI scans, which can be time-consuming and prone to human error.

This project aims to develop a **Convolutional Neural Network (CNN)** model that can automatically detect brain tumours from MRI scan images. By leveraging deep learning, the model learns to distinguish between **tumour** and **non-tumour** MRI images, assisting in faster and more accurate diagnosis.

---

## 🎯 Objectives
- Develop a CNN-based deep learning model to classify MRI images as tumour or non-tumour  
- Automate tumour detection to support radiologists and improve diagnostic efficiency  
- Evaluate performance using standard classification metrics  

---

## 🗂️ Dataset
- **Type:** MRI brain scan images  
- **Labels:** Tumour, Non-Tumour  
- **Format:** Image files (e.g., JPG, PNG)  
- The dataset undergoes preprocessing to improve model performance  

---

## 🛠️ Methodology

### 🔹 Preprocessing
- Image resizing  
- Normalization  
- Data augmentation  

These techniques help enhance model generalization and reduce overfitting.

### 🔹 Model Architecture
- Convolutional Neural Network (CNN)  
- Automatic feature extraction without manual feature engineering  
- Fully connected layers for classification  

---

## 📊 Performance Evaluation
The model is evaluated using the following metrics:

| Metric   | Description |
|----------|-------------|
| Accuracy | Measures overall correctness |
| Precision | Correct tumour predictions out of all tumour predictions |
| Recall | Ability to identify actual tumours |
| F1-Score | Harmonic mean of precision and recall |
